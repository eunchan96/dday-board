과제는 서버에 저장되고, 같은 보드 코드를 입력한 기기끼리 자동으로 동기화돼요.

과제 D-day

    보드가 만들어졌어요. 다른 기기(폰 노션 앱 등)에서 이 위젯을 열고 아래 코드를 입력하면 같은 과제가 보여요. 코드는 비밀번호 역할을 하니 다른 사람에게 공유하지 마세요.

    보드 코드 · 다른 기기에서 이 코드를 입력하면 연결돼요.

    스마트캠퍼스 연동 · 캘린더 화면 오른쪽 아래 "캘린더 피드" 주소를 넣으면 과제를 하루 3번(07시·13시·21시) 자동으로 가져와요. 주소는 서버에만 저장되고 다시 볼 수 없어요.

    이전 위젯 데이터 가져오기 · 예전 위젯의 "백업 / 불러오기"에서 복사한 텍스트를 붙여 넣으세요. 이미 있는 과제는 건너뛰어요.

    연결을 해제해도 서버 데이터는 남아 있어요.
